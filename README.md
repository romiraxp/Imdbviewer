# Просмотр базы IMDB
## Цель проекта: дать возможность пользователям искать товар в базе

### Описание проекта

    Проект реализован на фрэймворке Django. Для просмотра базы требуется пройти авторизацию. Пользователи добавляются через административную панель Django администратором проекта или определенным администратором кругом лиц.
